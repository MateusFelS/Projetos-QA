| CT-005 | Item com desconto no carrinho                                | Usuário na página inicial                                       | Adicionar 3 Café Expresso e confirmar a promoção                       | O item deve ser exibido no carrinho com a marcação "Discounted"                                         | O item exibiu a marcação "Discounted" corretamente após a confirmação da promoção.                                             | ✅ Passou                 | Alta       |
| CT-006 | Verificar promoção após 3 itens no carrinho                  | Usuário na página inicial                                       | Adicionar 3 Café Expresso                                              | Sistema deve exibir a mensagem promocional                                                             | A mensagem promocional foi exibida corretamente após o 3º item.                                                                | ✅ Passou                 | Alta       |
| CT-007 | Ausência de promoção com menos de 3 itens no carrinho         | Usuário na página inicial                                       | Adicionar apenas 1 Café Expresso                                       | Sistema não deve exibir a mensagem promocional                                                         | Nenhuma mensagem promocional foi exibida, conforme esperado.                                                                   | ✅ Passou                 | Média      |
| CT-008 | Promoção disponível após remoção dos itens que a ativaram      | Promoção confirmada com 3 itens no carrinho                     | Confirmar a promoção e remover os itens do carrinho                    | Sistema deve desativar a promoção quando os itens que a originaram forem removidos                     | A promoção permaneceu ativa mesmo após a remoção de todos os itens que a originaram.                                            | ❌ Falhou                 | Alta       |
| CT-009 | Limite de uma promoção por usuário                            | Promoção já confirmada com 3 itens no carrinho                  | Adicionar mais 2 Café Expresso após a promoção já ter sido confirmada  | Sistema não deve reativar/reexibir a mensagem promocional para o mesmo usuário                          | A mensagem promocional foi exibida novamente, indicando que o cupom pode ser acionado repetidamente pelo mesmo usuário.         | ❌ Falhou                 | Alta       |

> **Observação:** Os casos CT-008 e CT-009 evidenciam os defeitos descritos na seção "Problemas e Riscos" do README do projeto: o cupom permanece ativo após a remoção dos itens que o originaram, e pode ser acionado repetidamente para o mesmo usuário, gerando risco de perda de receita.
